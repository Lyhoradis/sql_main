# учет наличия статуэток в интернет-магазине
Мне перешло семейное дело - бутик сувенирных статуэток, который нуждается в системе учета
## Как работает база?
- Хранит список статуэток (название, материал, цена, остаток)
- добавляю новые товары в новые таблицы (одна таблица = физический контейнер)
- нахожу товары, которые заканчиваются
- Нахожу конкретный контейнер, в котором лежит товар
